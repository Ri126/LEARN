# Vở học tiếng Anh

App checklist theo dõi quá trình học tiếng Anh (chạy trên iPhone như một app, không cần Mac hay Xcode).

- **Hôm nay:** 5 việc học mỗi ngày, chuỗi ngày học đủ, tuần hiện tại.
- **Lộ trình:** checklist 5 giai đoạn từ Nền tảng đến B1 và củng cố.
- Dữ liệu lưu ngay trên máy (localStorage), hoạt động offline sau lần mở đầu.

## Đưa lên GitHub Pages
1. Tạo repo mới trên GitHub (ví dụ `hoc-tieng-anh`), để Public.
2. Upload cả 7 file trong thư mục này lên repo (Add file > Upload files > Commit).
3. Vào Settings > Pages > Source: chọn **Deploy from a branch**, nhánh `main`, thư mục `/ (root)` > Save.
4. Chờ 1-2 phút, link có dạng `https://TEN-GITHUB.github.io/hoc-tieng-anh/`.

## Cài lên iPhone
1. Mở link trên bằng **Safari**.
2. Bấm nút Chia sẻ > **Thêm vào Màn hình chính** > Thêm.
3. Mở app từ màn hình chính như app bình thường.
